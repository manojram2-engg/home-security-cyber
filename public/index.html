The automation: Nmap XML to vulnerability table

A short script reads every open service version from the scan, queries the local Exploit-DB copy, and prints one line per service. It turns a tool run into a repeatable pipeline.

#!/usr/bin/env python3
"""Nmap XML to searchsploit table. Run only on systems you own."""
import json, subprocess, sys
import xml.etree.ElementTree as ET

def services(xml_path):
    for host in ET.parse(xml_path).getroot().iter("host"):
        ip = host.find("address").get("addr")
        for p in host.iter("port"):
            svc = p.find("service")
            if svc is None or p.find("state").get("state") != "open":
                continue
            q = " ".join(filter(None, [svc.get("product"), svc.get("version")]))
            if q:
                yield ip, p.get("portid"), q

def searchsploit(q):
    r = subprocess.run(["searchsploit", "--json", q],
                       capture_output=True, text=True)
    return json.loads(r.stdout).get("RESULTS_EXPLOIT", [])

for ip, port, q in services(sys.argv[1]):
    print(f"{ip}:{port} | {q} | {len(searchsploit(q))} public exploit(s)")

    Passive: Shodan
    Search my own public IP and domain to learn what the internet already knows, with no traffic sent to the target. For a home lab behind NAT the expected result is nothing exposed, and that result goes in the report.
    

    Active: Angry IP Scanner and Nmap
    Angry IP gives a fast list of live hosts. Nmap then fingerprints services and versions on those hosts only. Scope is written down first: an isolated host-only network of lab virtual machines.
